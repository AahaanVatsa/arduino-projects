# Arduino Projects

A collection of my Arduino Uno projects using C++, including sensors, displays, motors, communication modules, and embedded systems.

## About

This repository contains my Arduino projects created using the Arduino IDE. It is used to track my progress, practice embedded programming, and build projects using a variety of electronic components.

## How to Run

1. Install the required libraries using the Arduino IDE Library Manager.
2. Open the desired project folder in the Arduino IDE.
3. Select **Arduino Uno** as the board.
4. Select the correct serial port.
5. Connect the required hardware components.
6. Upload the sketch to the Arduino Uno.
